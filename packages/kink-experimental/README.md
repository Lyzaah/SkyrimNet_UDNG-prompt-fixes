# SkyrimNet Kink Experimental

Tiny overlay. **Not in the Hard/Medium AIO.** Full write-up: [`EXPERIMENTAL.md`](../../EXPERIMENTAL.md) in the repo.

Adds `0730_kink_experimental.prompt`: SLO arousal bands, follower/friend remote play if she is plugged, ungag-to-feed if SunHelm ≥ 70. Combat omitted. Does not fire `ArousalChange`.

## Install

1. Have **World Setting Hard (AIO)** or **Medium (AIO)** enabled.
2. Drop this zip into MO2 as its own mod. Enable it.
3. Restart the game.

## Requirements

- The AIO (or Fix + Hard/Medium narrative)
- [SLO / OSL Aroused](https://www.nexusmods.com/skyrimspecialedition/mods/65454) for `sla_Arousal`
- [SkyrimNet_Arousal](https://github.com/GoodProvider/SkyrimNet_Arousal) owns the arousal action
- [SunHelm](https://www.nexusmods.com/skyrimspecialedition/mods/39414) for thirst/hunger (optional; missing → 0)
